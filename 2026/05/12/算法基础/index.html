1.3 适用情况

vector一般可以直接替换数组

有些情况普通数组无法解决：$n \times m$ 的矩阵，$1 \leq n$,$m \leq 10^6$且$n\times m\leq 10^6$

  • 如果用普通数组 int m[1000010][1000010],浪费内存，会导致MLE （我不知道）

  • 如果使用 vector<vector<int>> mat(n + 10, vector<int>(m + 10));，则可以完美解决该问题

另外，vector的数据存储在堆空间中，不会爆栈

1.4 注意事项

  1. 提前指定长度
    若长度指定，则应当直接在构造函数指定长度，而不是一个一个.push_back()。vector额外内存耗尽后的重分配是有时间开销的

4.0 优先队列priority_queue(堆)

#include<queue>

4.1 常用方法

构造

priority_queue<类型,容器,比较器>pque

  • 类型：要储存的数据类型
  • 容器：储存数据的底层容器，默认为vector<类型>，竞赛中保持默认就行
  • 比较器：比较大小使用的比较器，默认为less<类型>，可自定义
作用 用法 示例
进堆 .push(元素) que.push(1.0);
出堆 .pop que.pop();
取堆顶 .front int a=que.top();
查看大小 .size que.size();
判空 .empty que.empty

大顶堆：最大值在堆顶

小顶堆：最小值在堆顶

4.2 适用情形

持续维护元素的有序性：每次向队列插入大小不同的数，或者每次从队列中取出大小最大/最小的元素，元素数是n，插入操作数量k。

  • 每次插入后快速排序：$k\cdot n \log n$
  • 使用优先队列维护：$k \cdot \log n$

4.3 注意事项

仅堆顶可读
所有元素不可写

5.0 集合set

#include<set>
提供对数时间的插入，删除，查找的集合数据结构，底层原理是红黑树

集合三要素 解释 set multiset unordered_set
确定性 一个元素要么在集合中，要么不在 ✅ ✅ ✅
互异性 一个元素仅可以在集合中出现一次 ✅ ❌（任意次） ✅
无序性 集合中的元素是没有顺序的 ❌（从小到大） ❌（从小到大） ✅
