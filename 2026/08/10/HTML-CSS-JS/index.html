HTML + CSS + JS 入门

网页三件套，一个都不能少。它们的关系可以用盖房子来理解：

  • HTML = 毛坯房的结构：墙、门、窗、房间
  • CSS = 装修：墙纸、颜色、家具摆放
  • JS = 水电和智能家居：灯会亮、按钮有反应、家电会联动

一、HTML —— 网页的骨架

HTML（超文本标记语言）用标签来描述内容。绝大多数标签成对出现：

像包裹糖果的糖纸，一个开一个合。

最常用的标签

标签 作用 例子
<h1> ~ <h6> 标题（从大到小） <h1>我的博客</h1>
<p> 段落 <p>你好，世界</p>
<a> 链接 <a href="https://hexo.io">Hexo</a>
<img> 图片（自闭合） <img src="photo.jpg" alt="照片">
<ul> / <li> 无序列表 项目符号列表
<button> 按钮 <button>点我</button>
<div> 万能容器（一块区域） 用来分组、布局
<span> 行内小容器 给一小段文字单独上色

三、JavaScript —— 网页的大脑

JS 让页面动起来、有反应。三个最基础的概念：

1. 变量

2. 函数

3. 事件 + DOM（改页面内容）

document.getElementById(...) 是”去页面里找元素“，改它的 style、textContent 就是”操作页面“。前端最核心的动作就是这两步：找到它，改它。

五、接下来怎么学

  1. 改着玩：把示例里的颜色、文字、按钮改成你自己的，改一处刷新一次看效果
  2. 按 F12：在浏览器按 F12 打开开发者工具 → 元素/样式面板，能看到任意网页的结构和 CSS，甚至临时改着玩（刷新还原）
  3. 看你的主题源码：themes/sakura/ 里就是这三样——.ejs（模板，最终渲染成 HTML）、style.css、main.js，正好是活教材

一句话收尾：HTML 管”有什么”，CSS 管”长什么样”，JS 管”会做什么”。三者叠加，就是你每天浏览的网页。
