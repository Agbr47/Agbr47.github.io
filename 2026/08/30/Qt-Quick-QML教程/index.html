Qt Quick / QML 具体教程

1. 什么是 Qt Quick / QML

Qt Quick 是 Qt 提供的一套用于构建现代、流畅、动态界面的技术。

QML 是一种声明式语言，专门用来描述界面长什么样、如何布局、如何响应交互。

简单理解：

对比传统 Qt Widgets：

对比项 Qt Widgets Qt Quick / QML
界面描述 用 Python/C++ 代码创建控件 用 QML 声明式描述
适合界面 表单、列表、工具类软件 动画丰富、界面现代的软件
开发速度 一般 较快
动画能力 较弱 很强
与 Python 配合 很直接 需要通过上下文/信号桥接

无边框窗口注意事项

问题 处理方式
无法拖动窗口 必须用 MouseArea 自行计算 root.x / root.y
无法最小化 调用 root.visibility = Window.Minimized
无法最大化/还原 调用 root.visibility = Window.Maximized 或 Window.Windowed
无法关闭 调用 Qt.quit()
最大化后拖不动 在 onPositionChanged 中判断 root.visibility !== Window.Maximized
最大化后遮住屏幕边缘 可以保留圆角，或使用原生边框方案；最大化时也可以隐藏圆角
需要调整窗口大小 无边框窗口默认不能通过系统边缘拉伸，需要自己实现边缘 resize 逻辑

13. 常见问题

13.1 QML 文件加载不出来

检查：

  • 文件名是否正确
  • QML 是否在 main.py 同目录
  • 是否缺少 import QtQuick.Controls

13.2 Python 修改 QML 属性没反应

使用 property var xxx 或 property string xxx 声明属性后，再用 setProperty 设置。

13.3 QML 中中文乱码

  • 文件保存为 UTF-8
  • 数据库返回内容也统一使用 UTF-8

13.4 网络请求跨域

桌面客户端不是浏览器，通常没有跨域限制。
但如果是 WebAssembly 或 Web 混合模式，需要在 FastAPI 后端配置 CORS。

14. 总结

Qt Quick / QML 非常适合做：

  • 动物繁殖管理系统
  • 宠物管理软件
  • 数据展示看板
  • 动画丰富的桌面应用

核心学习路线：

只要掌握这些内容，就可以用 PySide6 + Qt Quick / QML 开发一套完整的桌面应用。
