第二天学习笔记

2.1 Git / Gitee 学习

1. 为什么使用 Git/Gitee？

随着项目越来越大，代码文件越来越多，仅靠复制保存容易出现以下问题：

  • 代码备份麻烦
  • 容易覆盖旧版本
  • 难以找回历史代码
  • 多人协作困难

Git 是分布式版本控制工具（Distributed Version Control System），可以：

  • 保存每一次代码修改（留痕）
  • 随时回退到历史版本
  • 多人协作开发
  • 管理不同功能的开发进度（分支）

Gitee 则提供了远程仓库，用于在线保存和共享 Git 仓库。

2. Git 与 SVN 的区别

SVN（集中式版本控制）

特点：

  • 所有代码存放在服务器
  • 必须联网才能提交代码
  • 公司现在使用较少

示意：

Git（分布式版本控制）

特点：

  • 每个人电脑都有完整仓库
  • 断网也能提交(commit)
  • 联网后再同步到远程仓库
  • 目前企业开发主流

示意：

3. GitLab、GitHub、Gitee

  • GitHub

    • 全球最大的代码托管平台
    • 国外网站

  • Gitee

    • 国内代码托管平台
    • 速度快
    • 学校和企业使用较多

  • GitLab

    • 可以自己搭建服务器
    • 企业内部经常使用
    • 安装维护较复杂

2.2 Qt 学习

1. Qt 介绍

Qt 是一个跨平台 C++ 图形界面（GUI）开发框架，既可以开发桌面软件，也可以开发嵌入式应用。

Qt 具有以下特点：

  • 跨平台（Windows / Linux / macOS）
  • 开发效率高
  • 丰富的 GUI 控件
  • 支持网络编程
  • 支持数据库
  • 支持多线程
  • 支持 OpenGL、3D 可视化

应用场景：

  • 汽车中控系统
  • 工业控制软件
  • 医疗设备
  • 智能家居
  • 上位机软件
  • 桌面客户端

2. 操作系统相关知识

进程（Process）

一个运行中的软件就是一个进程。

例如：

  • QQ
  • 微信
  • 浏览器

每打开一个程序，就会创建一个进程。

线程（Thread）

线程是进程中的一个执行任务。

例如：

浏览器可以：

  • 下载文件
  • 播放视频
  • 打开网页

这些任务通常由多个线程同时完成。

多线程

一个进程可以拥有多个线程，同时执行多个任务。

优点：

  • 提高程序运行效率
  • 防止界面卡死
  • 提升用户体验

Qt 提供了完善的多线程开发支持（如 QThread）。

3. Qt 版本

常见版本：

  • Qt 5.x（企业使用较多）
  • Qt 6.x（最新版本）

安装包：

4.3网络编程

什么是网络编程

网络三要素：

  • ip地址：像身份证一样，每个电脑唯一且不重复

  • 协议：发送方和接收方互相定义的一套规则，发送方用什么协议发送，接收方也要用什么协议接受

  • 端口号：每个人有一个唯一的端口号，用于软件之间的通信

  • 前提：电脑网络是可以相互ping通的

  • 网络结构：

    • BS：浏览器和服务器
    • CS：客户端与服务器
