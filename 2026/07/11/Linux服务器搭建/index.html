Linux 常用命令速查

📁 文件与目录

命令 功能
ls 列出目录内容
cd 切换目录
pwd 显示当前路径
mkdir 创建目录
rm 删除文件/目录
cp 复制文件/目录
mv 移动或重命名
touch 创建空文件
find 查找文件
tree 树状显示目录

📝 文本处理

命令 功能
cat 显示文件内容
less 分页浏览文件
head 查看文件头部
tail 查看文件尾部
grep 文本搜索
sed 流式文本编辑
awk 文本分析处理
sort 排序
uniq 去重
wc 统计行数/字数
diff 比较文件差异

⚙️ 系统管理

命令 功能
top / htop 动态进程监控
ps 查看进程快照
kill 终止进程
df 查看磁盘使用
du 查看目录大小
free 查看内存
uname 系统信息
lsblk 列出块设备
dmesg 内核日志
systemctl 管理服务

🌐 网络

命令 功能
ping 测试连通性
curl 网络请求/下载
wget 下载文件
ss 查看端口/连接
ip 网络配置
dig DNS 查询
ssh 安全远程登录
scp 远程拷贝

🔐 权限与用户

命令 功能
chmod 修改权限
chown 修改所有者
sudo 提升权限执行
su 切换用户

📦 包管理

发行版 命令示例
Debian/Ubuntu apt install / apt remove
RHEL/Fedora dnf install
Arch pacman -S

🗜️ 压缩归档

命令 功能
tar 归档/压缩/解压
gzip 压缩为 .gz
zip 跨平台压缩

🛠️ 其他

命令 功能
echo 输出文本
date 显示日期
history 命令历史
alias 设置别名
man 查看命令手册
