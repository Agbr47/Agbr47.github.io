Hexo 博客的日常操作几乎都集中在终端里，以下是最常用的命令，按使用场景分类整理。

一、环境准备与项目创建

如果已有项目，只需在博客目录下执行后续命令。

二、内容创作

文件名会自动以日期前缀命名，例如 2026-07-11-文章标题.md。

三、本地预览与调试

hexo s 是 hexo server 的简写，效果完全一样。

四、生成与清理

常用组合技：

hexo g 是 hexo generate 的简写，hexo d 是 hexo deploy 的简写。
上述组合命令可进一步简写为：hexo clean && hexo g -d 或 hexo d -g（先构建后部署）。

五、查看与管理

六、高级技巧 & 常用选项速查

场景 命令示例 说明
只生成最近 5 篇文章 hexo g --limit 5 预览时可加快速度
生成后自动部署 hexo g -d 或 hexo d -g 免去重复输入
强制覆盖部署 hexo d --force 部署时忽略本地与远端差异
不启动浏览器 hexo s --open 启动后自动打开浏览器 (部分环境可能无效)
忽略缓存重新生成 hexo g --force 强制重新生成所有页面
安全模式（不加载插件） hexo s --safe 排查插件问题用

日常最常见的工作流

这些命令已经覆盖了 Hexo 博客 90% 的日常维护需求，熟练掌握后效率会非常高。如果部署环节出现问题，务必先检查根目录 _config.yml 中的 deploy 配置是否正确。
