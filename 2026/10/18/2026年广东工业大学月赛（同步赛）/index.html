B题

链接：https://ac.nowcoder.com/acm/contest/142131/B

来源：牛客网

题目描述

结束了紧张刺激的牛客多校，unk 和可爱的队友们感到饥肠辘辘，来到了好口福。

经过一些观察，发现好口福共有 (n) 个座位，目前有 (k) 个空位。

unk 能预测到接下来会依次发生 (m) 个事件。所有事件组成一个长度为 (m) 的字符串 (s)：

  • 若 (s_i=0)，表示一名正在用餐的客人离开餐厅，空位数增加 (1)。若此时所有座位均为空，则空位数不变；
  • 若 (s_i=1)，表示一名客人到达餐厅。如果餐厅中存在空位，该客人会立即入座，空位数减少 (1)；否则，该客人需要等位。

unk 拥有一种魔法。每施展一次魔法，可以让一名正在用餐的客人立即暴风吸入食物，立即离开餐厅，立即空出一个座位。

她可以在任意时刻施展魔法。请计算至少需要施展多少次魔法，才能使每一名到达餐厅的客人都可以立即入座，无须等位。

输入描述

第一行包含一个整数 (T)（(1 \le T \le 10^4)），表示测试数据的组数。

对于每组测试数据：

第一行包含三个整数 (n,k,m)（(1 \le n,m \le 10^6)，(0 \le k \le n)），分别表示餐厅的座位数、初始空位数和事件数量。

第二行包含一个长度为 (m) 的字符串 (s)。字符串中的每个字符均为 (0) 或 (1)。

对于单个输入文件中的所有测试数据，保证 (\sum n+\sum m \le 10^6)。

输出描述

对于每组测试数据，输出一行一个整数，表示至少需要施展的魔法次数。

C题 小猪玩音游

链接：https://ac.nowcoder.com/acm/contest/142131/C
来源：牛客网

题目描述

小猪最近入坑了一个叫“吃你字母”的音乐游戏，每天两眼一睁就是出勤。每次下勤小猪都想看看自己的成绩，但是服务器太烂了，总是卡住查不到分，于是，小猪写了个程序决定算一算自己的 Rating。

游戏中共有 (N) 首歌曲，编号为 (1) 到 (N)。第 (i) 首歌曲有一个固定的定数 (d_i)，定数为恰好保留两位小数的实数。通过爬取服务器记录，查询到小猪一共进行了 (M) 次游玩，每次游玩记录包含歌曲编号和本次游玩的准确率（ACC）。

本题规定单次游玩的准确率（ACC）的输入范围为 (0.00%) 到 (100.90%)。

请注意，本题要求与现实音游中可能采用的定数计算方式不同，请按照题面计算。

对于一次定数为 (d)，准确率为 (a%) 的一次游玩，其单曲评分定义如下：

  • 当 (a < 97.50) 时，单曲评分为 (0)；
  • 当 (97.50 \le a \le 100.90) 时，单曲评分在 (d) 和 (d+2.15) 之间随准确率线性增长。也就是说，(a=97.50) 时单曲评分为 (d)，(a=100.90) 时单曲评分为 (d+2.15)。

因此，一次游玩等效的单曲评分为

[
S(d,a)=
\begin{cases}
0, & 0 \le a < 97.50, \
d+2.15\times \dfrac{a-97.50}{100.90-97.50}, & 97.50 \le a \le 100.90.
\end{cases}
]

计算 Rating 时，我们将所有歌曲的最高单曲评分从高到低排序，取前 (30) 个位置组成 B30（best 30th），作为计算分数的依据。

小猪可能多次游玩同一首歌曲。对于每首歌曲，只保留该歌曲所有游玩记录中的最高单曲评分；同一首歌曲最多只能在 B30 中出现一次。

没有游玩过的歌曲，以及不足 (30) 首歌曲时多出来的位置，都视为 (0) 分。小猪的 Rating 定义为 B30 中 (30) 个分数的平均值：

[
\text{Rating}=\frac{\text{B30 中 30 个分数之和}}{30}.
]

例如，小猪只游玩过一首歌曲，且这首歌的最高单曲评分为 (15.90)，那么 Rating 是

[
15.90/30=0.53.
]

现在给出所有歌曲的定数和小猪的全部游玩记录，请你计算他的 Rating。

输入描述

第一行包含两个整数 (N,M)（(1 \le N,M \le 2\times 10^5)），分别表示歌曲数量和游玩记录数量。

第二行包含 (N) 个实数 (d_1,d_2,\dots,d_N)（(1.00 \le d_i \le 20.00)），表示每首歌曲的定数。

接下来 (M) 行，每行包含一个整数 (s_j)（(1 \le s_j \le N)）和一个实数 (a_j)（(0.00 \le a_j \le 100.90)），表示第 (j) 次游玩的是第 (s_j) 首歌曲，准确率（ACC）为 (a_j%)。输入中的定数和 ACC 均恰好包含两位小数，且不带百分号。

保证至少有一条游玩记录。

输出描述

输出一个浮点数，表示小猪的 Rating。

如果你的答案与正确答案的绝对误差或相对误差不超过 (10^{-6})，你的答案将被视为正确。

形式化地说，设你的答案为 (x)，正确答案为 (y)。当且仅当满足

[
\frac{|x-y|}{\max(1,|y|)} \le 10^{-6}
]

时，你的答案才会被视为正确。

D题 课后作业

链接：https://ac.nowcoder.com/acm/contest/142131/D
来源：牛客网

题目描述

寺子屋的数学课上，慧音正在讲乘法持久性。

琪露诺听了不到三分钟，就趴在桌上睡着了，梦里还嘟囔着：“…最强…”

下课铃响，慧音布置完作业，朝她那边扫了一眼：“没做完的，别想走。”

琪露诺猛地惊醒，看到黑板上的课后作业：试在三进制下构造一个数，使其乘法持久性为 (x)。

琪露诺回忆了一下课堂内容，在本题中：

三进制：是以 (3) 为基数的进位制，只使用 (0)、(1)、(2) 三种数字表示数值，运算遵循逢三进一规则。例如：十进制下的数字 (4) 的三进制表示是 (11_3)。

乘法持久性：把一个正整数的各位数字相乘，再对所得的积重复这一操作，直到结果变成一位数为止，所需的步数就是这个数的乘法持久性。已经是一位数时，乘法持久性为 (0)。

本题中，每一步都将当前数视为三进制数，把它的各位数字相乘，并将结果继续写成三进制。

例如 (12_3) 的各位数字之积为 (1\times 2=2)，所以它的乘法持久性为 (1)。

一个核心猜想是：在十进制下，任何数的乘法持久性都不超过 (11)。目前已知乘法持久性达到 (11) 的最小数是 (277777788888899)，但尚未发现乘法持久性更大的数。

琪露诺听不懂这么复杂的东西，只好求助于可靠的你。
本题只考虑长度不超过 (38) 位的三进制正整数。

输入描述

输入一个整数 (x)（(0 \le x \le 11)），表示需要构造的乘法持久性。

输出描述

如果存在长度不超过 (38) 位的三进制正整数，使其乘法持久性恰好为 (x)，输出任意一个以三进制表示的满足条件的数。否则输出 (-1)。

请注意：除 (-1) 外，输出只能包含 (0)、(1)、(2)，不含有前导零。
(0) 不是正整数。

K题 野比大雄的射击训练

链接：https://ac.nowcoder.com/acm/contest/142131/K
来源：牛客网

题目描述

大雄有一个大小为 ((2n-1)\times(2n-1)) 的正方形飞镖盘。行和列均从 (1) 开始编号，中心格子的坐标为 ((n,n))。

飞镖盘由中心向外划分为若干个方形环。中心格子的得分为 (n)，围绕中心的第一圈共 (8) 个格子，得分均为 (n-1)。此后每向外一圈，得分减少 (1)，最外圈格子的得分均为 (1)。当 (n=1) 时，飞镖盘只有一个格子，其得分为 (1)。

现在有 (k) 支飞镖落在飞镖盘上，且落点互不相同。给定每支飞镖的落点坐标，请计算它们的总得分。

输入描述

第一行包含两个整数 (n) 和 (k)（(1 \le n \le 1000)，(1 \le k \le (2n-1)^2)）。

接下来 (k) 行，每行包含两个整数 (x_i) 和 (y_i)（(1 \le x_i,y_i \le 2n-1)），表示一支飞镖落在第 (x_i) 行、第 (y_i) 列的格子中。

保证所有坐标对 ((x_i,y_i)) 两两不同。

输出描述

输出一个整数，表示所有飞镖的总得分。

M题 教练！我想打xcpc！

链接：https://ac.nowcoder.com/acm/contest/142131/M
来源：牛客网

题目描述

广东工业大学 ACM 集训队正在整理区域赛报名信息。共有 (n) 支队伍。每条记录包含队伍名、赛站名、比赛日期和报名是否成功。

请输出所有报名成功的队伍。每行输出队伍名前加上 ，随后输出赛站名和比赛日期。输出行的顺序任意。

输入描述

第一行包含一个整数 (n)（(1 \le n \le 50)），表示队伍数量。

接下来 (n) 行，每行包含四项：

队伍名 赛站名 比赛日期 报名结果

其中：

  • 队伍名由大小写英文字母组成，长度不超过 (30)。所有队伍名两两不同。
  • 赛站名由小写英文字母组成，长度不超过 (10)。
  • 比赛日期的格式为 YYYY-MM-DD，且是合法日期。
  • 报名结果为 1 或 0：
    • 1 表示报名成功，
    • 0 表示报名失败。

保证每支队伍在输入中恰好出现一次。

输出描述

对于每条报名成功的记录，输出一行：

输出顺序任意。报名失败的记录不输出任何内容。如果没有队伍报名成功，可以不输出任何内容。
