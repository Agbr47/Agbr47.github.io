把照片放进 source/photos/，然后重新跑一次 npm run build， 它们就会自动出现在这一页，不需要写任何 Markdown。

支持 jpg / png / gif / webp / avif。默认按文件名排序，所以 01-、02- 这样的前缀可以控制顺序；说明文字默认取文件名（开头的序号会被自动去掉）。 想自己写说明就建 source/_data/photos.yml。
